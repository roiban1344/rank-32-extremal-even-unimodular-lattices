# verify/

[English](README.md) | 日本語

```
python3 verify/verify.py [report.json]
```

リポジトリのルートで実行する。必要なのは Python の標準ライブラリだけであり、すべての検査が通ると終了ステータスは 0 になる。
また、省略可能な引数を与えると、JSON の報告を書き出す。

### どの主張をどこで検査するか

行は、第 1 の論文の表 7 の行である。「入力」とは、検査がその値を certificate から取り、計算し直さないことを意味する。

| 表 7 の行 | 主張 | 検査する節 | ここでは計算し直さないもの |
|---|---|---|---|
| 1 | King のルートを持たない格子の質量 m | D（論文に印刷された値が certificate に等しい） | 質量そのもの |
| 2 | 可能な型（命題 3.3） | C（線形計画の 6 個の certificate。行はテータ級数の基底から作り直す） | モジュラー形式の基底 |
| 3 | 対合の成分 | I（等式 (B.1)、表 B3） | 成分の列挙 |
| 4 | 奇素数位数の成分 | I（表 B4 を質量と照合、(B.2) のステップ）、H（付録 D.4） | 種の質量、ルートを持たない格子の質量 |
| 5 | 貼り合わせの類 | I（83 個の組と 19 個の型についての等式 (4.1)。\|O(q_F)\| は補題 2.1 から） | 固定部分群 \|Stab(φ)\| |
| 6 | Gauss 構造についてのルートを持たない格子の質量 M_2 | E（(C.2) のすべての項をルートのデータから） | 2 進の局所的な統計 |
| 7 | Gauss 構造の一覧（命題 4.6） | I（Σ f/\|U\| = M_2。方法ごとの個数） | \|U\| と類の相異性 |
| 8, 9 | キー、有限群 | —（書かれた証明） | — |
| 10 | S_gen の格子（§6.3、補題 6.3） | F, G, I | 群が全自己同型群であること |
| 11 | 引き算（補題 6.6） | G | 行の識別子とキー |
| 12 | 等式 (5.1) | D | — |

### verify.py の節

| 節 | 検査 |
|---|---|
| A | `MANIFEST.json` に挙げたすべてのファイルが、記録した SHA-256 ダイジェストを持つ |
| B | 論文で引用したすべての計算が、その一覧表（表 11）にある |
| C | §B.1.1 の有理数上の 6 個の certificate: yA = 0 かつ yb = −1 を満たす乗数 y ≥ 0。および不等式そのもの。不等式は、保存したテータ級数と双対のテータ級数の基底から作り直し（正規化、係数の非負性、貼り合わせの等式）、q = 2j/p である類の数 N(j) は補題 2.1(i) によって (p, d, s) から計算し直す。基底、すなわちモジュラー形式の空間は入力である |
| D | 等式 (5.1): King の質量 m と分類した格子について、N = 2m + Σ (1 − 2/\|Aut L\|) が整数であること。定理 A と B に述べた総数。表 8。表 9 は論文から読み取り、データとセルごとに比較する |
| E | すべての埋め込みの平均 A_16(T) を、ルートのデータと保存した局所の 2 進の統計から `check_m2_terms.py` で計算し直す（統計、例外の係数、§C.3 の閉じた式は入力である）。(C.2) のすべての項（`gaussian-rootless-mass.json`）と、それに対する `root-coefficients.json` の数: 係数が既約な係数の積であること、命題 C.1 による \|U(T)\|、項 = c·A/\|U\|。その和は定理 4.5 の M_2 である。A_n、D_n、G_m の係数は §C.3 の閉じた式による |
| F | 整数で: 群が最大の 2 個の格子の生成元がその Gram 行列を保つこと。§6.3 の 106 個の等長写像が TᵀGT = G′ と det T = ±1 を満たすこと |
| G | §6 の数を分類した格子と照合する: S_gen の 12546 個の類。補題 6.3 については、保存した数（正確な識別子を持つ 12519 個の類）と保存した 27 個のプロファイル（各区分の中で互いに異なる）。S_(C_2^2) の 67284 個の格子。補題 6.6 の引き算については、certificate に保存した合計。次に、`general-part-witnesses.json` の行から: §6.3 の各結合の段階の後の類（識別子で 13396 個、逆の識別子を加えて 12585 個、等長写像を加えて 12546 個）。17736 件の全自己同型群の記録、その識別子、逆の辺、106 個の等長写像は、ちょうど 12546 個の類にまとまり、各類は一般の部分の格子を 1 個持ち、その記録と同じ \|Aut L\| を持つ。`general-part-identification.json` の項目と等長写像は、その格子の類に入る。補題 6.3 については、正確な型（識別子を欠く行を持たない型）を行から読み取り、12519 個の類のそれぞれが正確な型の証拠となる行（witness）を持ち、残りの 27 個の類は保存した 27 個のプロファイルの類にちょうど一致して、互いに異なる。補題 6.6 については、引き算を個々の項目の集合の差として行う: \|Stab\| = 4 である極値の対合の項目（および \|Aut K\| = 2 である型 (8, 24) の項目）から、自己逆な項目と S_gen の項目を除いたものは、S_(C_2^2) の 67284 個の格子の向きつきの項目にちょうど一致する。76742 個の Gauss 構造のキーから S_gen の 11545 個のキーを除いたものは、S_CQ の 63499 個の格子のキーにちょうど一致する（巡回群では f = 2 かつ \|U\| = \|Aut L\| のキーが 1 個、四元数群では f = 1 かつ \|U\| = 4, 4, \|Aut L\|/2 のキーが 3 個）。849 個の四元数の格子については、`quaternion-triples.json` から整数で: 2547 個の Gram 行列 G のそれぞれが対称、偶、正定値（首座小行列式を Bareiss の消去法で求める）であり、det G = 1 を持つ。i 倍の行列 W は W G Wᵀ = G と W² = −1 を満たす（W は行ベクトルに作用する）。各三つ組で、TᵀG_first T = G_second と det T = ±1 を満たす 2 個の等長写像 T がその 3 個の類をつなぐ（1698 個の等長写像。どの類もちょうど 1 個の三つ組に入る）。各三つ組の 3 個のキーは、`general-part-witnesses.json` の `cq_lattices` にあるそのラベルのキーにちょうど一致し、\|U\| と f は `gaussian-list-weights.json` のとおりである。入力であり、ここでは検査しないもの: 記録の群が全自己同型群であること、その共役類の行が完全であること（型、中心化群の位数）、行の識別子と Gauss 構造のキーが正しいこと、逆の識別子と自己逆な識別子、項目をつなぐ肯定的な等長写像（§6.3 の 106 個と四元数の三つ組の 1698 個については、T^T G T = G' と det T = ±1 だけを F と G の節で検査する）。Gauss 構造の類のキーと \|U\| がその (G, W) のものであること、および Gauss 構造の類の相異性。後者によって、異なる三つ組は異なる格子になる（命題 6.5） |
| H | 有限の検査を再実行し、その certificate と比べる: 9-ねじれの簡約（`check_exponent9.py`）と、付録 D.4.6 の初等的な 2 次の 2-形式の軌道（`check_quadratic2_orbits.py`、次元 1 から 20 の 230 個の形式のすべて） |
| I | 完全性の等式を、その項から足し直す: 成分のすべての組の \|O(q_F)\| を補題 2.1 の閉じた式から求める（F の階数とその Gram 行列の s、δ から、または型 p-(z,f)-s から）。等式 (4.1) を、対合の成分の 83 個の組について（成分の s、δ と 2-初等性は Gram 行列から求める）、および 19 個の奇素数位数の型の組について（258 個の組では項ごとに、5-(6,8)-6 の 4 個の組では分解の数から、極値の貼り合わせを持たない 3-(6,20)-6 の 2 個の組では記録した質量から）。表 B4 の成分の一覧を、その種の質量またはルートを持たない格子の質量と照合する（(B.2) で完成させた一覧では、ルートを持たない格子の質量は検査である）。表 B4 に用いた (B.2) の段階を \|U(Z_+)\| と g(Z_+) から項ごとに検査し、これらの段階が、連続するレベルの一覧を、ルートを持たない格子の質量に届く一覧 (z, z) までつなぐこと。型 (8, 24) についての等式 (B.1)（A_2^12 については、良い 3 次元部分空間の 106624 個の軌道の項から）、および \|Aut K\| を qfauto で計算した 4 個の格子 K の位数を、ほかのどの K も持たないこと。76742 個の Gauss 構造の類についての Σ f/\|U\| = M_2（命題 4.6）、および重みが各方法（標準形、バックトラック探索、bliss）から得られた類の数がその証明に述べたとおりであること。標準形による類は、標準形のキーを持つ類にちょうど一致し、\|U\| = 4 かつ f = 2 を持つ。表 5、6、B3、B4 の数。補題 6.3(ii): §4.1–§4.2 のすべての一覧について、S_gen の 12546 個の格子の行（各格子につき記録 1 件）を足すと、その一覧の極値の質量から、S_(C_2^2) に割り当てた自明な類を除いたものになり、後者はどれも行の識別子ではない。識別子を持つ行は、\|C\| = \|Stab\| である相異なる類を与え、質量だけで保存した組は 3-(6,20)-6 の極値でない組である。S_(C_2^2) と S_gen の一覧の項目は、その一覧の極値の類であり、S_gen の全自己同型群の記録にある位数 3 の識別子はどれも、その一覧の極値の両側剰余類であって、\|Stab(φ)\| がその行の中心化群の位数に等しい |

**ここで検査しないもの.** 完全性の等式はその項から足し直すが（I 節）、
項そのものは計算し直さない: 自己同型群と固定部分群、分解の数と良い直線の数 g(Z_+)、種の質量とルートを持たない格子の質量、
および一覧の類が相異なることを保証する等長性の判定である。これらは論文の議論（表 7）と、
ソフトウェアについての仮定（表 10）に基づく。なお、これらを計算したプログラムは研究記録（リリースの添付ファイル
`research-record.tar.gz`）にある。

## verify_p2.py（第 2 の論文）

`python3 verify/verify_p2.py [report.json]` は、第 2 の論文の 99 個の格子のデータ `data/largest-groups.jsonl` を、
整数の厳密な算術で検査する（Python の標準ライブラリだけを用いる。約 1 分）:

| 節 | 検査の内容 |
|---|---|
| A | 99 個のラベル: 相異なり、`32.<\|Aut L\|>.<i>` の形で、表 A1 の順に並び、それぞれ `data/classified-lattices.jsonl` の対応する行と同じ \|Aut L\| を持つ |
| B | 各 Gram 行列: 整数、対称、偶、det 1、正定値 |
| C | Aut L の各生成元 g: g^T G g = G かつ det g = ±1 である整数行列 |
| D | 各表示（第 2 の論文の §2.3）: その行列が G を保つ。その補題が要求する関係がすべてあり、右辺は後の段に属し、整数行列の上で成り立つ。Aut L のどの生成元も保存した語の積に等しく、したがって表示の行列は Aut L を生成する。補題の上界が \|Aut L\| に等しい |
| E | データにある表 A1 の列が `paper/p2-lattices-99.json` に等しい。\|Aut L\| の因数分解と各表示の補題が表と一致する |
| F | プロファイル: すべての共役類について、大きさ × 中心化群の位数 = \|Aut L\| であり、そのフレームシェイプは次数 32 で、固有値 1 の重複度が固定格子の階数に等しく、a_1 がトレースに等しい。類の大きさの和は \|Aut L\| で、単位元の類は 1 個である。最短ベクトルの上の軌道の和は 146880 である。類そのもの（GAP で計算した）は入力である |

計算し直さないもの（第 2 の論文の §2.5 の仮定）: 位数 \|Aut L\| そのもの、および
有限表示の商と単純切片の位数。後者は、剰余類の数え上げで直接、または
補題 2.4 の鎖に沿って数えたものである。スクリプトはこれらの位数を入力として表示したうえで、補題 2.4 の鎖の整合性を検査する。

## verify_database.py（データベースのリリースの添付ファイル）

`python3 verify/verify_database.py database-v2.tar.gz [report.json]` は、データベース [D]、
版 2 のリリースの添付ファイルを、このリポジトリと照合する（Python の標準ライブラリだけを用いる。約 30 分、メモリは 1.2 GB）。なお、添付ファイルが無いときは
SKIP と表示し、ステータス 0 で終了する。また、`--label 32.<|Aut L|>.<i>` を付けると、1 個の格子の記録を表示する。

| 節 | 検査の内容 |
|---|---|
| A | 行を収めたすべてのファイルが、アーカイブのマニフェストにある大きさ、SHA-256 ダイジェスト、行数を持つ。行は全部で 143329 行 |
| B | 索引は `data/classified-lattices.jsonl` のすべてのラベルをちょうど 1 回ずつ、ラベルの順に持つ。どの行も索引の示す場所にあり、定理 B のその部分のファイルに入っていて、ラベルの位数 \|Aut L\| を持つ |
| C | すべての Gram 行列が偶、正定値で、行列式が 1 である |
| D | すべての生成元が g^T G g = G を満たす整数行列 g である |
| E | \|Aut L\| <= 10^6 である 143316 個の格子について: 保存した生成元が生成する群による、ある整数ベクトルの厳密な軌道が \|Aut L\| 個の元を持つ。D によりこの群は Aut L の部分群であるから、第 1 の論文の位数を認めれば、Aut L の全体である |

検査しないもの: 格子がルートを持たないこと、\|Aut L\| > 10^6 である 13 個の格子の生成元が Aut L の全体を生成すること、異なるラベルが
異なる格子であること。これらは第 1 の論文の主張であり、その証明に基づく。
