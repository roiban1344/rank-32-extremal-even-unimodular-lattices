# certificates/

[English](README.md) | 日本語

各ファイルは JSON のオブジェクトであり、フィールド `certificate`（表題）、
`statement`（何を保証するか）、`computations`（論文の表 11 の行）、`scope`（何を示し、何を示さないか）を持ち、
その後にデータが続く。大きいファイルでは、各フィールドと、リストの各要素が、それぞれ一行をなす。`verify/verify.py` は、すべてのファイルを
`MANIFEST.json` のダイジェストと比較し、すべての certificate の内容を、ファイルに述べられた範囲で論文と照らして検査する。
ほとんどの certificate では、検査は、等式をその項から計算し直すこと、保存した行から集計を再実行すること
（補題 6.3 と 6.6 については `general-part-witnesses.json`）、整数行列の検査
（`quaternion-triples.json` のような等長写像と Gram 行列）、または有限な検査の再実行である。
どれであるか、および各検査が入力に取るものは、`verify/README.md` に書いてある。

## 識別子

格子は、データベースのラベル `32.<|Aut L|>.<i>` で呼ぶ（論文の §6.8）。
§4 の一覧の項目は、一覧の識別子 `<list>:<index>` で呼ぶ。ここで `<list>` は型と成分の組を表す:
表 5 と 6 の対合の型については `15-17`、`14-18<K>`、`12-20-c<K>`、`16-16-s<s>d<delta><F,K>`、`16-16s14`（s = 14、
delta = 1）、`16-16d8`（s = 16、delta = 1）、型 (8, 24) については `8-24`、
表 4 の奇素数位数の型については、p = 3 では `<z>-<f>-<s>`、p >= 5 では `<p>-<z>-<f>-<s>` である。
対合の一覧では、`<index>` は `involution-gluing-masses.json` の中の、その組の一覧での類の位置であり、
`8-24` では `type-8-24-masses.json` の中の K の位置である。
p = 3 では、項目は `<z>-<f>-<s>:<i>-<j>/<k>` である: `odd-prime-masses.json` のそれぞれの種の、
最小ノルムが 4 以上である i 番目の格子 F と j 番目の格子 Z（`genera_F` は一覧の順で、`min4` を持つ類だけを数える。`genera_Z`）
の組の k 番目の両側剰余類であり、これはその組の `stabilizers` の k 番目の項目である。
例外は、全自己同型群の記録の背後にある構成の名前としてだけ用いるもので、次のとおりである: `13-6-5:<j>` は
3-(13,6)-5 の j 番目の格子 Z との組（F は一意で、両側剰余類は 1 個）、`6-20-6:<h>/<k>` は
3-(6,20)-6 の組を、F のハッシュの先頭の 16 進 12 桁と剰余類の番号で呼んだもの、`<p>-<z>-<f>-<s>:<n>` は
研究記録の中の、その型の n 番目の極値の組である。`record:<i>` は、他の方法で作った格子
（付録 A の既知の格子）の全自己同型群の記録である。

全自己同型群の記録（`general-part-witnesses.json`）の行は型を持つ: 対合では `inv:<list>`、
位数 3 では `3-<z>-<f>-<s>`、p >= 5 では `odd:p=<p>:f=<f>` である。p >= 5 の行は s を記録しておらず、どれも
識別子を持たないので、粗い名前が型を正確にすることはない（補題 6.3）。Gauss 構造の類は
そのキーで呼ぶ（§7.2）: `k` に 16 進 24 桁が続くものは標準形の Gram 行列のハッシュ、`D` に
16 進 16 桁が続くものは不変量 D であり、後者は §7.2 の直線の選び方が標準形の Gram 行列を与えないとき
（選んだ直線が L を生成しないか、その色が直線を順序づけないとき）に用いる。
リリースの添付ファイルも同じ識別子を用いる。

## c2xc2-part.json

S_gen に現れない自明な対合の項目。F = K の場合は [phi] と [phi^-1] を同一視する（補題 6.6(i)）。それぞれが Aut L = {+-1, +-sigma} である格子を 1 個与える。

*範囲.* 一覧の項目とその格子。貼り合わせの一覧の完全性と識別子の正しさは入力である（§4、補題 6.6）。

## exceptional-full-groups.json

|Aut L| = 2 |最短ベクトルの直線の軌道| |最短ベクトルの固定部分群|。§7.1 のアルゴリズムで Gram 行列だけから計算した。

*範囲.* Gram 行列、計算した位数、生成元（列の規約: g^T G g = G）。生成元は整数で検査する。それらが全自己同型群を生成することは、§7.1 のアルゴリズムの出力である。

## gaussian-list-weights.json

*範囲.* 各類について: そのキー（§7.2 の標準形のキーまたは不変量のキー）、|U|、f。位数 |U|、フラグ f、類の相異性は、ここでは入力である（命題 4.6 と表 10）。Gram 行列は、Gauss 構造の類のリリースの添付ファイルに同じキーで入っている。weight_methods[i] は、classes[i] の (|U|, f) をこの値で与えた方法の名前である（canon: 標準形、search: バックトラック探索、bliss: bliss による Aut L と GAP による中心化群。+ でつなぐ）。方法ごとの個数は、命題 4.6 の証明のものである。

## general-part-witnesses.json

補題 6.3: 保存した S_gen の全自己同型群の記録、その正確な識別子、逆の識別子、整数の等長写像は、12,546 個の類につながる。類は一般の部分の格子 1 個につき 1 個である。12,519 個の類は、識別子を持つ正確な型の行（下の証拠となる行）を持ち、残りの 27 個はプロファイルを保存した類である。補題 6.6: |Stab| = 4 である極値の対合の項目（および |Aut K| = 2 である型 (8, 24) の項目）から、自己逆な項目と S_gen に現れる項目を除いたものは、ちょうど S_(C_2^2) の向きつきの項目である。命題 4.6 の Gauss 構造のキーから S_gen に現れるものを除いたものは、ちょうど S_CQ の格子のキーである。

*範囲.* S_gen の成功した全自己同型群の記録のそれぞれについて（格子が一覧の項目でないとき、record:<i> は i 番目の記録を表す）: その一覧の項目、|Aut L|、その項目（§6.1）の行 [行, 種類, 型, 識別子または null, 中心化群の位数, 自己共役]。行は、sigma != +-1 である対合の項目 {[sigma], [-sigma]} ごとに 1 行（自己共役: sigma が -sigma と共役で、項目が 1 個の類である）と、奇素数位数の元の共役類ごとに 1 行である。さらに、位数 4 のエルミートの行 [行, キー, |U|, f]。加えて、逆の辺 [phi] -- [phi^-1]（general-part-identification.json の 8,716 個の逆の識別子と、そのうち 6 個の逆向き。非順序対 5,005 個）、general-part-identification.json の等長写像の辺、一般の部分の各格子のデータベースでの出所、各類の証拠となる行、高い殻のキーで補った行、自己逆な項目、および S_CQ の各格子の Gauss 構造のキー。verify/verify.py は、これらの行と他の certificate から集計を再実行する。補題 6.3(ii) の等式も含む: 各一覧について、S_gen の格子の行を、記録 1 個ずつ、重み 1/|C|（F = K である一覧の、自己共役でない対合の項目では 2/|C|）で足すと、その一覧の極値の質量から S_(C_2^2) に割り当てた自明な類を引いたものになる。全自己同型群、完全な共役類の行、正しい識別子とキー、正しい自己逆と逆の識別子、等長であると判定した等長写像を条件とする（表 10）。これらはどれも、ここでは計算し直さない。

## odd-prime-masses.json
